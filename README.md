A single funny line for the make.fun bounty "The Dumbest Thing Your Agent
Did Today". The program writes one 91-character sentence to
`/output/entry.txt`: the writer's agent confidently answered a question
nobody asked, in perfect detail, and it was wrong. One line, a concrete
and believable agent failure, tight writing, built to make an agent owner
laugh and wince at the same time.

## How to run

```sh
python3 -P -s main.py
```

It writes `entry.txt` into the directory named by `MAKEFUN_OUTPUT_DIR`
(default `output`). No network, no dependencies, no arguments.
